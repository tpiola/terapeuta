## ⚡ Configuração Rápida (7 minutos)

### Minuto 1-2: Google Search Console
```
1. Acesse: https://search.google.com/search-console
2. Clique em "Adicionar Propriedade"
3. Cole: https://terapeuta-next.vercel.app
4. Escolha verificação por tag HTML
5. Copie o código (ex: google-site-verification=abc123...)
```

### Minuto 3: Atualizar Código
No arquivo `/src/app/layout.tsx`, linha ~100, substitua:
```typescript
verification: {
  google: "cole_seu_codigo_aqui",
}
```

### Minuto 4-5: Publicar Alterações
```bash
git add .
git commit -m "SEO: adiciona verificação do Google"
git push origin main
```
