# Espaço Crie & Ative — Elis Regina (Terapeuta Holística)

Website institucional oficial do **Espaço Crie & Ative**, conduzido pela terapeuta holística **Elis Regina** (CRTH-BR 13579 / ABRATH).

## 🌿 Sobre o Projeto
- **Localização:** Parque Moema — Franca/SP (Atendimento presencial e on-line).
- **Especialidades:** Cone Hindu, Cromoterapia, Radiestesia com Pêndulo, Radiônica, Estudos Anatômicos de Meridianos / Reflexologia, e Apometria On-line.
- **Stack Tecnológica:** HTML5 Semântico, CSS3 Moderno (Luxury Editorial Motion, pure CSS Scale-Up interactions, responsive CSS Grid/Flexbox), Schema.org LocalBusiness, e conformidade rigorosa com a LGPD (Lei nº 13.709/2018).
- **Performance:** 100% estático, carregamento instantâneo, zero dependências pesadas em tempo de execução.

## 🔒 Diretrizes do Repositório
- Este repositório oficial é **único e protegido** em `https://github.com/tpiola/terapeuta`.
- Travas de segurança estão configuradas para manter a integridade da branch `main` e impedir a criação acidental de repositórios paralelos.
