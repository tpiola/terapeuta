# Terapeuta

Site profissional para terapeutas — landing page moderna, otimizada para captação de pacientes e agendamento de consultas.

Site em produção: [terapeuta-ten.vercel.app](https://terapeuta-ten.vercel.app)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:3000 para ver o resultado.

## Build

```bash
npm run build
```

## Deploy

Deploy automático via Vercel a cada push na branch `main`.
